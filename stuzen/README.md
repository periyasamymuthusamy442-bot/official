# STUZEN TECHNOLOGIES — Official Website
**Tagline:** Learn. Build. Innovate.  
**Domain:** Website Development | Custom Software | AI & Automation

---

## 🌟 Overview
A next-generation, high-performance website built with **HTML5, CSS3, and JavaScript (ES6+)**. The platform digitizes Stuzen Technologies' official 11-page **Website Project Requirements Discovery Form** and implements a modern, clean light aesthetic inspired by Microsoft's design system (lavender/ice/mint hero slider, yellow badges, 3D device mockups, a "For business" 4-card grid, and interactive 24/7 AI assistant).

---

## 🚀 Website Structure & Pages

1. **`index.html`** (Flagship Homepage)
   - Microsoft-style interactive **Hero Slider ("Slidebar")** with autoplay, `< >` navigation, and `⏸ / ▶` pause/play toggle.
   - **"For business" 4-card grid** on a soft powder-blue canvas.
   - Core Service Pillars (Web Development, Custom Software, AI & Automation).
   - The Stuzen 4-Stage Methodology ("Learn. Build. Innovate. Scale").
   - Featured Case Studies, Client Reviews, and FAQ Accordions.
   - Floating "Back to top ↑" button & "Can we help you?" popover dialogue.
   - WhatsApp direct chat button & Stuzen AI Assistant chatbot window.

2. **`discovery.html`** (Digital Requirements Discovery Wizard)
   - 10-step digital questionnaire covering all 45 questions from the official Stuzen Discovery Form PDF.
   - Live cost and delivery turnaround estimation engine.
   - 1-click **Send Requirements via WhatsApp** (pre-formatted brief).
   - **Print / Save as PDF** with custom print stylesheet.
   - Download Project Brief JSON & Discovery Acknowledgement Signatures block (matching PDF Page 11).

3. **`services.html`** (Capabilities & Transparent Pricing)
   - In-depth technical breakdown of Web Development, Custom Software, AI & Automation, E-Commerce, and Cloud DevOps.
   - 3 Transparent Pricing Tiers: Starter Web ($499), Growth Business ($1,499), Enterprise & AI ($3,499+).

4. **`portfolio.html`** (Filterable Case Studies & Detail Modal)
   - Interactive category filtering (All, Web, Software, AI Automation, E-Commerce).
   - Demonstrable business ROI metrics (+320% inquiries, 75% overhead reduction, 99.99% uptime).
   - Interactive **Case Study Detail Modal** displaying technical architecture, client challenge, Stuzen solution, and tech stack tags.

5. **`about.html`** (Company Profile & Culture)
   - Mission, vision, core values, unbloated technology ecosystem, and Stuzen Operating Code.

6. **`contact.html`** (Contact & Booking)
   - Direct message inquiry form, WhatsApp click-to-chat, office details, and interactive location card.

## 💻 How to Run Locally

You can open any HTML file directly in your web browser, or serve the directory using:

```powershell
# Python
python -m http.server 3000

# Node.js
npx serve .
```

Navigate to `http://localhost:3000` in your browser.
